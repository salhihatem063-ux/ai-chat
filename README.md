# AI Chat — واجهة محادثة ذكاء اصطناعي

واجهة دردشة كاملة البنية، قابلة للربط بأي نموذج لغة متوافق مع واجهة **OpenAI-compatible API** (مثل Ollama، LM Studio، vLLM، llama.cpp server، Mistral، وغيرها).

## البنية
- `server.js` — خادم Node.js (Express) يعمل كوسيط (proxy) نحو النموذج، ويحفظ الإعدادات والمحادثات محليًا.
- `public/` — الواجهة الأمامية (HTML/CSS/JS) بدعم عربي كامل RTL ووضع داكن/فاتح.
- `settings.json` — تُنشأ تلقائيًا لحفظ الإعدادات.
- `conversations/` — تُنشأ تلقائيًا لحفظ المحادثات.

## التشغيل

```bash
cd ai-chat
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## ربط نموذج

من **الإعدادات** (زر ⚙ في الشريط الجانبي) حدّد:

| المزوّد | Base URL |
|---|---|
| Ollama | `http://localhost:11434/v1` |
| LM Studio | `http://localhost:1234/v1` |
| llama.cpp server | `http://localhost:8080/v1` |
| vLLM | `http://localhost:8000/v1` |

ثم اختر النموذج من القائمة المنسدلة في الأعلى (أو اكتب اسمه يدويًا).

### مثال: تشغيل نموذج عبر Ollama
```bash
ollama serve
ollama pull llama3.1        # أو أي نموذج آخر
```

## متغيرات البيئة (اختيارية)
- `PORT` — منفذ الخادم (افتراضي 3000).
- `AI_BASE_URL` — عنوان النموذج الافتراضي.
- `AI_API_KEY` — مفتاح API (إن وُجد).
- `AI_MODEL` — اسم النموذج الافتراضي.

## المزايا
- بثّ الردود لحظيًا (streaming) مع مؤشر كتابة.
- حفظ المحادثات محليًا + حذف + فتح.
- موجّه نظام مخصص + ضبط الحرارة و Max Tokens و Top-P.
- تصدير المحادثة بصيغة Markdown.
- نسخ الرسائل وأكواد البرمجة بضغطة زر.
- إعادة توليد الرد.
- دعم RTL كامل ووضع فاتح/داكن.

## ملاحظة
النموذج الذي يغذّي الموقع هو من اختيارك وتشغيلك أنت. هذا المشروع هو **واجهة** فقط، ولا يتضمن أي نموذج مضمّن.
